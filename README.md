# 🌌 数字绿洲 (Digital Oasis) - 个人博客系统

欢迎来到**数字绿洲**。这是一个融合了**极致视觉动效**与**舒适阅读体验**的现代化全栈个人博客系统。该项目基于“内容即代码”的设计哲学，将轻量化数据库持久层与 Markdown/MDX 本地文章编译引擎完美结合，并配有极具个性的交互式流体粒子背景与双模玻璃拟物态卡片设计。

---

## 🎨 核心特性

### 1. 🌌 极致的视觉体验与交互美学
*   **Canvas 流体粒子背景**：内置响应鼠标手势的交互式流体物理特效背景（`InteractiveFluid`），让页面充满生命感与动态张力。
*   **磨砂玻璃拟物态 UI**：全站卡片大量采用磨砂玻璃感（Glassmorphic UI），配有平滑的渐入动效（Fade-in）和触碰微悬浮交互。
*   **双模自适应**：原生支持现代暗黑/明亮双模切换，在低对比度和高对比度环境下都表现优异。

### 2. 📝 “内容即代码”的文章引擎
*   **Markdown/MDX 渲染**：文章以原生 `.md` / `.mdx` 文件格式保存在本地，通过 `gray-matter` 提取 Frontmatter 元数据，并使用 `marked` 解析为排版优雅的 HTML。
*   **自动版本备份**：在后台编辑器中编辑文章时，系统会在修改前自动在 `content/posts/backups` 目录下建立当前版本的时间戳备份，防止内容意外丢失。
*   **智能阅读预估**：根据文章字符密度，动态估算并展现“预计阅读时间”。
*   **分类标签云**：动态提取并加权统计全站标签，提供可交互的标签筛选。

### 3. 💬 树形嵌套互动评论区
*   **无限级树形嵌套**：支持评论的多级回复与点赞操作，层级脉络清晰。
*   **哈希像素艺术头像**：系统根据用户的 IP 及特征哈希，动态在前端生成并渲染特有的**像素艺术（Pixel Art）SVG 头像**，保障隐私的同时充满极客趣味。
*   **离线 IP 地理反查**：安全记录并解析显示评论发表者的物理位置。

### 4. 📈 自适应 UV 流量统计
*   **物理去重统计**：利用 SQLite 的唯一性联合索引，服务端提取真实 IP 并写入 `PostIpView`，从物理层面上规避刷量，保障唯一访客量（UV）的精确统计。
*   **自适应降级查询引擎**：查询支持 Prisma 引擎与原生 SQL 极速降级双模运行，天然绕过模块缓存限制。

## 📂 项目目录结构

```text
├── content/               # 博客文章存放目录
│   └── posts/             # 原生 Markdown (.md / .mdx) 文章
│       └── backups/       # 后台编辑文章时自动生成的历史版本备份
├── prisma/                # Prisma 数据库配置
│   ├── dev.db             # 本地 SQLite 数据库文件
│   └── schema.prisma      # 数据库模型定义 (Comment, PostView, PostIpView)
├── public/                # 静态资源文件
├── scripts/               # 辅助脚本
│   └── db-setup.js        # 数据库冷启动初始化脚本
├── src/
│   ├── app/               # Next.js App Router 路由与页面
│   │   ├── admin/         # 后台管理主页
│   │   ├── api/           # 后端 API 接口 (评论管理、文章管理、访问量等)
│   │   ├── posts/[slug]/  # 文章详情渲染页 (包含智能 TOC 与评论区)
│   │   └── page.tsx       # 前台首页 (服务器渲染，流体背景挂载)
│   ├── components/        # 可复用 React 组件
│   │   ├── admin/         # 管理端专属页面组件 (WritePage, CommentsPage)
│   │   └── ...            # TOC, InteractiveFluid, CommentForm, CommentsSection
│   ├── lib/               # 核心底层工具类
│   │   ├── auth.ts        # 登录认证拦截
│   │   ├── avatar.ts      # 像素哈希头像生成引擎
│   │   ├── db.ts          # Prisma 客户端初始化
│   │   └── posts.ts       # 本地 Markdown 读取与解析服务
│   └── styles/            # 全局样式与 CSS 变量设计系统
├── next.config.js         # Next.js 配置文件
├── package.json           # 项目依赖与运行脚本
└── tsconfig.json          # TypeScript 配置文件
```

## 🛠️ 快速开始

### 1. 克隆并安装依赖
在项目根目录下执行以下命令安装所需的依赖包：
```bash
npm install
```

### 2. 启动开发服务器
运行开发脚本。启动时系统会自动检测本地 SQLite 数据库并应用迁移，同时如果检测到文章目录为空，会自动为您注入一篇极具设计感的欢迎博文：
```bash
npm run dev
```
启动成功后，在浏览器中访问 [http://localhost:3000](http://localhost:3000) 即可进入您的数字绿洲。

### 3. 后台管理登录
点击页面顶部的“写作后台”按钮，或直接访问 `/admin`。
*   **注**：后台提供了完整的文章撰写/修改、草稿箱管理、版本回溯、评论审核与删除等功能。

### 4. 生产环境打包与部署
在生产环境中打包项目：
```bash
npm run build
npm run start
```
